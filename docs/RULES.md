# 官方规则与实现对照（RULES）

> 版本：v2 ｜ 日期：2026-10-07 ｜ 适用：`rulesVersion = 2`（官方 Blokus 四人规则）
> 变更背景：v1 把"同色/异色"的接触方式实现反了，已按官方规则修正并保留 v1 校验器用于回放历史对局。

## 1. 官方四人 Blokus 规则

### 1.1 棋盘与棋子

- 20×20 棋盘，四角为四位玩家的起始角。
- 每人 21 块：1 格 ×1、2 格 ×1、3 格 ×2、4 格 ×5、5 格 ×12，合计 **89 格**。

### 1.2 开局

- 每人的**第一块**必须**覆盖自己的起始角格**（角格必须被该棋子的某一格占据）。
- 四人顺序：蓝（左上 A1）→ 黄（右上 T1）→ 红（右下 T20）→ 绿（左下 A20）。

### 1.3 后续落子（核心三原则）

| # | 规则 |
| --- | --- |
| 1 | 新棋子必须与**至少一块同色棋子角对角接触**（对角相邻） |
| 2 | **同色棋子之间禁止边贴边**（正交相邻） |
| 3 | **异色棋子之间允许边贴边**，但**禁止角对角接触** |

图示（`.` 空 / `B` 蓝 / `Y` 黄）：

```
同色【合法】角接触          同色【非法】边接触
B .                        B B
. B                        （共享一条边）

异色【合法】边接触          异色【非法】角接触
B Y                        B .
（共享一条边）               . Y
```

### 1.4 PASS 与终局

- 轮到某人但无任何合法落点时，必须 PASS。
- 实务上"PASS 一次"="出局"：落子只会让可用空间更小，之后不可能重新获得着法。
- 所有玩家都 PASS 或出完全部棋子时，对局结束。

### 1.5 计分

- 终局统计各自的**剩余格数**，最少者获胜。
- 若有玩家出完全部 21 块，获得奖励：**+20 分**；若最后一块恰好是单格 `I1`，则为 **+15 分**。
- 本实现显示为 `score = -剩余格数 (+奖励)`，**分高者胜**，与"剩余最少者胜"等价。
- 平局：官方版本按"先出完者优先"处理；本实现目前仅按分数排序（相同分数并列，未做进一步细分）——列为已知差异。

## 2. 常见误区（本次修正的原因）

| 误区 | 正确理解 |
| --- | --- |
| "同色要连成一片（边相邻）" | ❌ 同色只能**角相连**，边相邻反而违规 |
| "不能贴着对手的棋子放" | ❌ 异色**可以**贴边，这是一条重要战术手段 |
| "和对手斜着挨着没关系" | ❌ 异色**禁止**角对角接触，斜着贴是违规的 |
| "PASS 之后还能再下" | ❌ 实际不可能再获得着法（空间只会更小） |
| "出完 21 块 +20，最后单格也是 +20" | ❌ 最后落单格时为 **+15** |

## 3. 本实现对照

| 规则点 | 官方 | 实现（v2） | 状态 |
| --- | --- | --- | --- |
| 首子覆盖起始角 | 必须 | 必须（`not_corner`） | ✅ |
| 同色接触 | 必须角相邻 | `no_own_corner` 拒绝无角接触 | ✅ |
| 同色边相邻 | 禁止 | `same_color_edge` | ✅ |
| 异色边相邻 | 允许 | 不拦截 | ✅ |
| 异色角相邻 | 禁止 | `opposite_corner` | ✅ |
| PASS | 无着法才可 | `has_moves` 拦截 | ✅ |
| 终局 | 全员无着法/出完 | 一致 | ✅ |
| 计分 | -剩余格数；+20 / 单格 +15 | 一致 | ✅ |
| 平局细则 | 先出完者优先（部分版本） | 未实现 | ⚠️ 已知差异 |
| 2/3 人对局 | 官方无（2 人为 Duo 14×14） | 自定义变体：2 人蓝/红对角；3 人蓝/黄/绿 | ⚠️ 变体，已在 DESIGN 注明 |

## 4. 规则版本与兼容

| 字段 | 含义 |
| --- | --- |
| `rulesVersion: 2` | 官方规则，新对局默认写入；棋谱导出为 `Rules: v2` |
| `rulesVersion: 1` | 旧版变体（同色边相邻、异色禁止边相邻），仅用于**回放历史对局** |
| 缺省（无该字段） | 按 v1 处理（兼容本次修正前保存的存档与棋谱） |

- 引擎 `rules.js` 同时保留 `canPlaceV1`（旧）与 `canPlaceV2`（官方），由 `state.rulesVersion` 分派。
- 旧对局在新版本中：**回放正常**（用 v1 校验器重放），界面会标注「旧规则对局（v1）」；无法切换为官方规则重放。
- 需要把旧对局"迁移"到官方规则是不可行的（着法合法性不同），只能作为历史记录保留。
