# R1–R12 验收与正确性记录

> 日期：2026-10-08 ｜ 版本：v1.1.0 ｜ 基线：AGENTS.md 第 2 节 ｜ 操作：M9 / M10

## 1. 当前结论

R1–R12 的基线功能均已实现；M9 修正规则和计分，M10 补齐数据可靠性、联机生命周期与文档契约。
「实现」不等于所有设备已现场验收：R4 已通过同机双页面完整对局和服务重启测试，真实两台设备、防火墙和多网卡仍待现场确认。
R12 要求 AI 设计和接口参数文档，已完成；可玩的 AI 对手不属于当前范围。2/3 人简化模式明确标注，不冒充官方人数变体。

| 优先级 | 改善 | 原因/建议验收 |
| --- | --- | --- |
| P1 | 真实多设备、网络断开/防火墙、多网卡与不同浏览器验收 | 两台设备完整四人局、断线恢复、主机重启恢复；避免只凭同机 CDP 推断网络环境 |
| P1 | 移动触控/键盘/读屏和色盲可用性 | Canvas 棋盘目前偏桌面；需要真实手机、焦点导航和色彩之外的识别方式 |
| P2 | UI 职责拆分 | ui.js 同时管理路由/网络/存储/回放；按控制器拆开可减少后续扩展回归，保持传统 script 与零依赖 |
| P2 | 合法着法性能 | 当前枚举遍历朝向与全部锚点；先测大局面耗时，再缓存/限定候选角点，保持判定一致 |
| P2 | 更稳健的服务数据写入 | 当前单进程 JSON 快照；服务磁盘失败时的完整事务、更多房间与并发压力测试尚未提供 |
